## Course Projects

### [The Pet Shop Website](The-Pet-Shop-Website)

A foundational multi-page HTML website for a pet shop. It includes navigation, pet image sections, an embedded video, a contact page, and a structured footer. This project helped me practise page structure, links, images, tables, multimedia, and navigation between pages.

### [One Page Website](one%20page%20website)

A single-page recipe website with bookmark navigation, a recipe gallery, an embedded video, a contact form, and a back-to-top link. This project demonstrates semantic page sections, internal links, images, forms, and embedded media.

### [Simple Recipes](Simple-Recipes)

A detailed recipe website with a navigation bar, rollover menu, featured recipe, multiple recipe categories, images, preparation instructions, CSS styling, and JavaScript. It demonstrates organized content, interactive navigation, responsive presentation, and separating HTML, CSS, and JavaScript into dedicated folders.

### [Creating CSS Effects](Creating-CSS-Effects)

An Aurora Space Resort website created to demonstrate custom typography and interactive CSS effects. It uses Google Fonts, responsive layouts, image overlays, hover effects, transforms, filters, and transitions.

### [Academy Cinemas](Academy-Cinemas)

A responsive cinema website built with Bootstrap 5 and custom CSS. It includes a responsive navigation menu, movie cards, showtimes, ticket selections, images, and media-query styling for different screen sizes.

### [Portfolio Website](Portfolio-Website)

A personal portfolio that brings together the HTML and CSS skills developed throughout the course. It includes a responsive header, hero section, about section, project cards, profile link, contact form, hover effects, animations, and mobile-friendly layouts.

## Skills Practised

- CSS layouts, typography, transitions, transforms, filters, and hover effects
- Responsive design and media queries
- Bootstrap components and grid layouts
- Organizing projects with separate HTML, CSS, JavaScript, and image files
